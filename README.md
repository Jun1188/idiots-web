[웹사이트 열기](https://jun1188.github.io/idiots/)

검증된 HTML·CSS·JavaScript와 공개 이미지의 정적 스냅샷을 보관합니다. 내부 문서, 비공개 자료, 원본 저장소 이력은 포함하지 않습니다.

- 반영일: 2026-11-11
- 공개 산출물: index.html, source-status.json, media의 이미지 8개
- 티노는 기본 4명이며 사이트의 관리 메뉴에서 1~8명으로 조절할 수 있습니다.
- 프로젝트 기여자는 각 게임의 공개 소스 기록을 근거로 표시합니다. 다운로드 빌드의 전체 제작진과 같다고 단정하지 않습니다.
- Awesome 뉴스·자료 수집은 후속 검토 대상이며 자동 수집 중이라고 표시하지 않습니다.

티노는 한국공학대학교 캐릭터를 바탕으로 만든 픽셀 표현이며 이 사이트는 학교 공식 홈페이지가 아닙니다.


## 대표사진과 제작진

Field Notes는 검토된 게임잼·교류회·NC 기업탐방·PlayX4 대표사진 4장을 이전/다음, 키보드, 터치로 탐색합니다. 신규 단체사진 배포본은 원본 픽셀을 유지하고 메타데이터와 후행 모션 데이터를 제거했습니다. 사진 원본 폴더 전체를 공개하지 않습니다.

모두의 카페 제작진은 공개 게임 코드의 실제 크레딧에 따라 김다니엘·김선웅·변준영·하준호를 표시하며, GitHub 커밋 작성 계정과 별도로 구분합니다.

## 작은 미니게임

Tino Run·앵그리티노·티노 디펜스를 Previous/Next로 고르고 직접 시작합니다. 앵그리티노는 각도·힘 발사 퍼즐, 티노 디펜스는 고정 경로의 배치·강화와 짧은 웨이브 게임입니다. 기존 픽셀 티노와 자체 코드·도형으로 만들었으며 원작 게임의 캐릭터·맵·코드는 복제하지 않았습니다. 게임별 버튼/키보드 안내와 일시정지를 제공하고, 선택을 바꾸거나 화면에서 벗어나면 멈춥니다.
