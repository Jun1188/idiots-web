평면 통로와 공중 지원 시설

티노 몸을 클릭·터치해서 잡고 이동하세요. 오른쪽으로 휙 움직이며 놓으면 더 멀리 날아가요. 티노는 평면 통로로 다가옵니다. 위 발판은 시설만 설치하는 공간입니다. 오른쪽 화면 밖이나 아래로 보내면 회수 완료 +100점.

키보드: Tab으로 티노 선택 → Space로 잡기 → 방향키로 옮기기 → Space로 오른쪽 투척. ‘다음 티노 선택 / 보내기’ 버튼으로도 플레이할 수 있어요. P/Escape는 일시정지.

3분 후 남은 티노까지 보내면 성공. 교수님과 시험지에 10명이 들어오면 다시 도전해요. 시설은 패드당 하나, 방어탑은 감속·공격탑은 아래 통로의 적을 밀어내기. 멈춤·다른 탭에서는 시간이 흐르지 않습니다.
